Dark-field X-ray microscopy produces large image stacks that need careful processing before they become strain and tilt maps. I develop Python pipelines covering:

- image **registration** and **denoising**
- **Q-space transformation**
- **strain and tilt** calculation

I also built a **machine-learning denoising workflow** for more accurate centre-of-mass evaluation in diffraction microscopy, which **won the Machine Learning for Microscopy Hackathon 2** (2026).
